### 💡 Architectural Philosophy

> *"The hardest challenge in production AI is rarely invoking an LLM—it is engineering the deterministic, observable, and secure software architecture around it."*

1. **Deterministic where possible, probabilistic where necessary:** LLMs should never calculate critical math, interest rates, or financial ratios. We enforce pure Python rule engines for business constraints and use LLMs for semantic extraction and natural language synthesis.
2. **Observability precedes deployment:** Every agent step, query latency, and database transaction must be structured, logged, and monitored (via CloudWatch/SSM) before reaching production.
3. **Security by topology:** Zero-bastion architectures via SSM, isolated database subnets with no public ingress, automated Trivy container scanning, and PKCE-enforced OIDC tokens.
4. **Interface rigor:** Strict schema boundaries (Pydantic v2, OpenAPI, explicit LangGraph state contracts) prevent decay across distributed teams.
